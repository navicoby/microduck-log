# MicroDuck 강화학습 훈련일지

소형 이족보행 로봇 MicroDuck의 보행·점프·기립을 시뮬레이션에서 학습하고 평가한 기록입니다. 실험 조건, 관측 결과, 해석과 후속 가설을 구분해 다른 사람이 유사한 실험을 설계할 때 참고할 수 있도록 정리했습니다.

- [훈련일지 읽기](https://navicoby.github.io/microduck-log/)
- 기록 범위: 2026년 9월 1~24일
- 기반 코드: [pollen-robotics/microduck_rl](https://github.com/pollen-robotics/microduck_rl)

공개 내용은 실험 요약, 도표, 시뮬레이션 영상입니다. 개별 실행의 원자료와 체크포인트는 제공하지 않으며, 수록된 결과는 실제 로봇에서의 성능 검증을 뜻하지 않습니다. 기반 코드의 저작권과 라이선스는 원저작자를 따릅니다.

`index.html`이 사이트 본문이며 `media/`에 시뮬레이션 이미지와 영상을 보관합니다. GitHub Pages에서 별도 빌드 없이 제공합니다.
